About this project

This is a 5th Semester Design and Analysis of Algorithms (DAA) mini project. It implements Huffman Coding, a classic greedy algorithm, to perform lossless file compression and decompression.

The project also compares Huffman Coding against a simple Fixed-Length Encoding baseline to demonstrate why frequency-based variable-length codes are useful.

What you can do here

  1. Compress a text file using Huffman coding.
  2. Decompress a compressed file and verify it matches the original.
  3. Run the performance experiment to measure compression ratio, execution time, and compare with the fixed-length baseline across small/medium/large datasets.

How Huffman Coding works

Frequency Table
      ↓
   Min Heap
      ↓
 Huffman Tree
      ↓
    Codes
      ↓
 Encoded Data

At every step, the algorithm greedily combines the two least frequent nodes. This local, greedy choice produces a tree that gives shorter codes to frequent symbols and longer codes to rare symbols.
